
# BLACKCUT | Barbería

Página web demostrativa para una barbería, desarrollada como proyecto de aprendizaje y portafolio frontend.

BlackCut presenta los servicios de una barbería mediante una interfaz moderna, responsive y orientada a facilitar el contacto con potenciales clientes.

## Vista previa

🌐 [Visitar BLACKCUT Barbería](https://nachofuentesinostroza.github.io/barberia/)

## Tecnologías utilizadas

- HTML5: estructura semántica del sitio.
- CSS3: estilos y personalización visual.
- Bootstrap 5: componentes y diseño responsive.
- JavaScript: funcionalidades interactivas.
- Git y GitHub: control de versiones y publicación.

## Funcionalidades

- Menú de navegación responsive.
- Portada con imagen y botón de reserva.
- Sección de servicios con precios.
- Presentación de la barbería.
- Galería de fotografías.
- Información de contacto y ubicación.
- Integración con WhatsApp para iniciar conversaciones de reserva.
- Enlace configurable a Instagram.
- Indicador dinámico del horario de atención.
- Diseño adaptable a celulares, tablets y computadores.

## Cómo ejecutar el proyecto

1. Descargar o clonar el repositorio.
2. Abrir la carpeta del proyecto en Visual Studio Code.
3. Abrir index.html con la extensión Live Server.
4. Visualizar la página en el navegador.

No requiere instalar dependencias con npm.

## Configuración

Los datos de contacto y las redes sociales se pueden modificar desde los archivos del proyecto.

El botón de WhatsApp permite iniciar una conversación, pero no confirma automáticamente una reserva.

## Objetivo de aprendizaje

Este proyecto fue desarrollado para practicar la construcción de interfaces web, el diseño responsive y la integración de funcionalidades mediante JavaScript.

Durante el desarrollo se realizaron pruebas en diferentes tamaños de pantalla, revisión de enlaces y corrección de errores visuales.

Se utilizó GitHub Copilot como herramienta de apoyo para la generación, revisión y mejora del código.

## Alcance

BlackCut es un proyecto demostrativo de portafolio.

No incluye backend, base de datos, procesamiento de pagos ni un sistema de agendamiento propio.
